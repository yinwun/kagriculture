# 新架构立项判断书（草稿，供 review）

日期：2026-09-19 · 状态：**仅思路，未开工** · 目的：先说清楚"值不值得做、怎么做、什么时候停"，再决定是否投入。

---

## 0. 一句话

我们已经用 ~1,400 局证明"从零发明一个经济"是撞墙的（plan_v0：**0/400 胜**）；但今天又用抽取证明**前沿也没换数据**——它和我们是同一份磁带（三个 route 数据块**逐字节相同**，sha256 `54fe156ea7206e38`）。所以真正没试过的不是"另一种经济"，而是**把现成那份能赢的计划（41×719 步动作序列）编译成显式、可统一优化的模型**——先求 parity，再求超越。本文把这条路拆成有闸门的阶段，并给出 kill 标准。

## 1. 已测事实（决策依据，全部来自本仓库实测）

**A. 磁带谱系本身是有效的，且其参数空间已被我们自己穷尽**

- 在榜线：`outer_prem` 对旧冠军 +597 (t=9.87) / +676 (t=10.70，样本外镇子)；叠加版 +790 / +1,099；对已提交线合并 60 镇 +372 (t=4.18)。
- 完美信息 oracle（完全知道对手排布）只有 **+513/+963**；强制反符号 **−15,307 (t=−18.35, 0/60)**。⇒ 市场排布杠杆已吃掉 80–100%，**不是**可挖的空间。
- 今天十项机制逐一关闭：畜群组成、羊日数与买卖时点、照顾/饲喂覆盖、小麦产量与物流、路由选磁带（其他磁带全部差 3k–9.8k）、扩展前卖品种、预测对手排布、鲁棒决策规则、加宽搜索、跨窗口重上架。
- 结论：**同一份数据 + 更少的层 = 输**；差距在被证伪的每一项之外，即"共同演化的经济"。

**B. 从零架构（plan_v0）已被判死，且失败原因被诊断清楚了**

| | planopt v0 | 冠军 rgcs |
|---|---|---|
| delta / t（200 城配对 400 局） | **−113,479 / −87.85** | — |
| W/L | **0 / 400** | 400 / 0 |
| wallet | 26,214 | 139,693 |
| 总收入 | **12,865** | **72,077** |

分产品（量 @ 均价）：WHEAT 424@**25.7** vs 187@**94.2**；STRAWBERRY 9@3.6 vs 105@137.6；MELON 0 vs 48@238.8；MILK 91@9.8 vs 132@74.9。

⇒ 冠军经济是**三层同时成立**：①组合（草莓/甜瓜/牛奶为主体）②**价格操作**（全季买饲料抽干小麦池，把麦价从基准 25 抬到 94，再抛自己的小麦）③计量卖出时点。**前置条件是早期现金率。** 分层移植、规格回放、混合、组合切换、现金加速、加鹅、卖出侧闭环、25 维联合搜索（14 镇最好 −85,696，40 镇复核仅 +679/0.7%）——全部失败。

**C. 今天新增的能力（plan_v0 时代没有）**

1. `scripts/lockstep.py`：对引擎逐槽/逐单位撮合与价格模型的**精确复刻**（12,942 次价格校验 + 400 组随机撮合 + 2,872 真实 player-step，**0 误差**）。⇒ 现在任何"如果改成 X 会怎样"都能在**本地精确预演**，不必靠直觉。
2. 步时限有**巨大余量**：整 agent 每步 mean 0.5 ms / p95 0.8 ms / worst 56.5 ms。⇒ **搜索式/滚动优化控制**在算力上完全可行（这是真正的新自由度）。
3. 仪器纪律与陷阱清单：配对对战是唯一有效仪器（对 starter 调参无效）；层异常会被外层 `try/except` 静默吞掉（`layer_fallbacks` 必须为 0）；**不同参数给出逐字节相同结果是 bug 签名**；第 6 天商店抽取与杂草共用当日 RNG ⇒ **计划改动会翻转整条磁带，只能整局配对判定**。

## 2. 三条候选路线

| 路线 | 内容 | 被判死的证据 | 判断 |
|---|---|---|---|
| **A. 端到端 RL / 自博弈** | 从观测直接学策略 | plan_v0 是"从零发明经济"的等价物，0/400；RL 面对**同一前置条件**（先得有能自持的共同演化经济），且样本效率在这个 719 步、双人共享市场的环境里极差 | **不作为第一步** |
| **B. 计划编译器 + 统一参数空间**（本文推荐） | 先把在榜磁带经济体**编译成显式模型**，验证 parity，再在**同一参数向量**上做联合搜索/优化 | 从未做过：过去的分层移植是"把层塞进黑箱磁带"，联合搜索是在**另一个**（plan_v0）经济上做的 | **先做** |
| **C. 继续抠前沿复合体** | 一层层抽出它 ~120 层 | 今天抽出**一层**（开盘第 0 步改麦单 5/10/60→13/30/30）：对冠军 +632，但对我们叠加版 **−166**；按此单价凑 +4,400 需几十层且要处理干扰 | 兜底，不主动 |

路线 B 的关键论点：**磁带本身就是"计划数据"**——41 条 × 719 步的显式动作序列，已被证明能拿 139k wallet。它不可优化的唯一原因是**表示形式**（固定动作序列），而不是它的经济是错的。把这份经济**编译**成"调度表 + 反应式控制器"，就同时得到：(i) 与冠军同源的经济（parity 可达）；(ii) 一个**统一的**参数向量（组合 × 价格操作 × 卖出时点住在一起）⇒ 过去"共同演化"无法搜索的根本障碍消失；(iii) 可解释的残差（哪里编译不出来，就定位到缺了哪个概念）。

## 3. 阶段与闸门（每阶段都可判定、可 kill）

**S1 — 编译器与保真度（约 2–3 天）**
- 产物：`scripts/compile_plan.py` → 显式表示 θ（每日/每象限的种植表、浇水与施肥优先级、动物买入日与数量、建造/放置编排、市场侧的逐日卖出表 + 价格门规则）+ 反应式控制器；以及 `scripts/fidelity.py`（把 θ 跑过引擎，与磁带 trace 逐步对比：动作一致率、wallet、分产品量/价）。
- 闸门 1a：纯磁带 agent 通过该管线**逐步动作 100% 复现**（先证明管线无损）。
- 闸门 1b：θ-拟合 agent 在 **20 个镇**上 wallet 落在冠军的 **±5%** 内。**达不到就停下来定位残差**（哪一类动作/哪一时段编译不出来），不要往下走。
- 成本：低（无新算法，只是表示与拟合）。

**S2 — Parity（约 1–2 周，关键墙）**
- 目标：θ agent 对冠军 **delta ≥ 0 且 t ≥ 3**（60 镇配对，样本内 + 样本外）。
- 手段：先做**结构性补齐**（用 S1 的残差定位缺哪个概念），再小步搜索；每一步都用配对对战，不用筛选器。
- Kill：累计 ≥ 200 次配对对战（或 3 周）仍未过 parity ⇒ **停止**，回到路线 C 或收线。理由：plan_v0 已经证明"经济不对"是 0/400 的量级，不该再重复。
- 成本：中；风险集中在这一阶段。

**S3 — 超越与联合优化（仅当 S2 通过）**
- 目标：对**当前在榜叠加版** delta > 0 且 t ≥ 3；然后把 25 维/更多维联合搜索搬到这个"从 parity 出发"的参数空间上（这才是当年 joint_search 想做但地基不对的事）。
- 附加自由度（今天才有）：把 `lockstep.py` 接成**滚动优化控制**——每个 contested 回合用精确撮合预演少量候选，算力预算充裕（worst 步 56 ms，余量以数量级计）。
- 闸门：分阶段提交纪律不变（今日配额 5，不 churn；只有过 t≥3 才提交）。

**S4（可选，另立项）**：非磁带的一般化——把 θ 的结构当作归纳偏置做 RL/自博弈。**只有 S3 证明"统一参数空间能产出可泛化的策略"之后**才谈。

## 4. 已知风险与前置条件

1. **表示的表达力**是 S1/S2 的真风险：若冠军经济里有我们没识别的概念（例如某种跨品种现金耦合），残差会卡在 parity 之下。缓解：残差定位是**可解释**的（定位到具体动作/时段），比 plan_v0 的黑箱失败好得多。
2. **RNG 耦合**：任何计划改动都可能翻转第 6 天商店抽取 ⇒ 整条磁带换掉。所有候选必须整局配对，不能筛选；这会限制迭代速度（每候选 2–4 分钟 × 60 局 × 2 面板）。
3. **仪器纪律**：只能用配对对战；层异常/参数无差异等 bug 签名必须当阻断项。
4. **提交配额纪律**：不 churn；只有过 t≥3 才消耗配额。
5. **期望值要诚实**：即使 S3 成功，榜顶 3,277、top1% 线 2,838 远高于"前沿候选本身"（+4,407 ≈ +4.4%），也就是说 S3 的成功**未必**等于冲进 top1%。本立项的合理目标是"把这条谱系的天花板从 ~top 10–15% 抬到能验证的新高度"，**不是**承诺名次。
6. **时间成本**：S1–S3 现实估计 **1–3 周**；S2 失败是**可能且合法**的结局。
