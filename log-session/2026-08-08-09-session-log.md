## 3. Working methodology (CLAUDE.md golden rules)

> **Source**: `/data/app/sandbox/kaggle/kagriculture/.claude/CLAUDE.md`

1. **L4 replays are the only truth** — 8 theoretical patches all failed; only L4 data-driven fixes worked
2. **Self-play A/B is gate check only** — adopt if ≥67% win rate, 5+ seeds × 2 sides
3. **Change only one variable at a time** — never batch changes
4. **No changes without L4 data** — no theoretical improvements
5. **Walk-forward replay evaluation is also low discrimination** — v4 and v1 both 100% crush replay opponents

### kagriculture environment specific
- Environment name has **double g**: `kagriculture`
- `kaggle-environments==1.32.6` required (1.32.2 too old)
- Shed inventory is private (can't know opponent's stock)
- Market prices deterministic analytic functions (not simulated)
- Daily submission limit: **~2 per day**
- Latest 2 submissions are tracked for final evaluation
- Scoring: **Bradley-Terry** (not absolute margin)
